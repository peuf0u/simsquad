# App notes

Standing knowledge about this app for the people and the agent workers who
test it. Every simsquad-test worker reads this file before it touches a
device, so anything that saves a worker from guessing belongs here. It is
yours: `simsquad skill install` created it once and never changes it.

## Getting around

How to reach the main areas of the app: tabs, menus, deep links, screens
that only appear after a certain step.

## Test accounts

Which accounts or personas to use on which stage, and where their
credentials come from (for example the squad env keys `user` and
`password`). Keep real secrets in the squad env, not here.

## Known quirks

Behaviour that looks like a bug but is expected: slow first launch, a
consent dialog, a debug menu, flaky staging endpoints.
